# Вариант 1. Отладочные классы C#

В работе реализованы две программы с использованием `System.Diagnostics`:

1. Вычисление синуса через ряд Тейлора.
2. Вычисление гиперболы f(x) = 1/x с обработкой точки разрыва x = 0.

## Где и какие инструменты применены

| Инструмент                | Где применён                                 | Что ловит / показывает                                                                          |
| ------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `Debug.Assert`            | В `CalcSin` и `Guard.CheckX`                 | Проверяет диапазон x, точность eps и деление на 0 (только в режиме Debug).                      |
| `Debugger.Break()`        | В `Guard.CheckX` при `                       | x                                                                                               | < 1e-9` | Останавливает отладчик, если x почти равен нулю. |
| `[DebuggerDisplay]`       | Над классами `TaylorResult` и `Point`        | Удобно показывает поля объектов при наведении мыши в отладчике.                                 |
| `Debug.WriteLine`         | В цикле ряда Тейлора и в `CalcPoint`         | Выводит промежуточные шаги расчета в окно Debug Console.                                        |
| `Debug.Indent / Unindent` | В функции факториала `Fact`                  | Делает отступ в логах при заходе во вложенную функцию.                                          |
| `TraceSource`             | В обоих проектах (`SinTaylor` и `Hyperbola`) | Пишет логи: Verbose (шаги), Warning (окрестность 0 или >100 итераций), Error (при x=0 или NaN). |
| `Stopwatch`               | В `Main` обоих проектов                      | Замеряет время выполнения расчетов и постройки таблицы.                                         |

## Разница между Debug и Release

- В режиме **Debug** (запуск через F5 или `dotnet run`) при вводе `x = 0` срабатывает `Debug.Assert` и `Debugger.Break()`, а в консоль отладки выводятся все шаги через `Debug.WriteLine`.
- В режиме **Release** (`dotnet run -c Release`) проверки `Debug` отключаются. При попадании в `0` программа не вылетает, а просто пишет в консоль слово "разрыв" и продолжает строить таблицу дальше.
